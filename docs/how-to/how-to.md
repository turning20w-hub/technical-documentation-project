# how-to/
### How to add an image in your html file? 
1. Upload & Name the required image file in your Neocities dashboard. For example: chaos.jpg
2. Open the respective html file you want to add your image in.
3. Add the code for example - 
`<img src="chaos .jpg" alt="chaos" width="600" height="400">`

[ To learn how to add am image using the direct link check out our guide on ##How to add image using link ] (https://github.com/turning20w-hub/Neocitiesd/blob/main/README.md#how-to-add-image-using-a-link) 

> If the image doesn't appear, check that the filename in the src attribute exactly matches the uploaded filename, including capitalization and file extension

### How To Add Image Using A Link 
1. Open your respective file.
2. Using the sample code -
   `<img src="add your URL" alt="A">`
   
### How to manage blog posts via dashboard? 
1. Simple create a new file with your blog name. For example - Todaysshow.html 
2. Add your content by opening the file and save.
