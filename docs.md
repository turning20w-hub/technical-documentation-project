## You'll create your first homepage today. 
1. Sign up by using your credentials on Neocities.org. 
2. If you face a password error you will click on forgot password to make a new one. You'll receive the link via email to process that. 
3. You'll go on dashboard page "neocities.org/dashboard" 
4. Click on "New File" 
5. You'll add a file name for eg. home.html and click on create. 
6. You'll make sure .html is added to access the same file later. 
7. Search for "home.html" file in your dashboard list and click. 
8. You'll see a code backend where you'll be adding the code. 
9. You'll add the code using the html language. 
10. On arranging your code in the "home.html" file click on "Save" 
11. Clicking on the "home.html" directly will take you to page that is live.
